# ASCIIGen frames

"hole"

Standalone animation data. No player or framework dependency is included.

Frame format
- Each animation contains quality folders (medium, low, or high), or frames directly in its root for older animations. Use an existing quality; prefer medium, then low, then high, then the root. Read that folder's meta.json for the actual width, height, fps, frameCount, colorMode, and frameEncoding.
- Frames are numbered from 1: frame_00001.txt or frame_00001.bin. Pad the index to at least five digits. Exports contain individual files, with no compressed bundle to decode.
- Monochrome: frameEncoding is utf8 (or meta.json is absent). Read .txt as UTF-8 and preserve every space and newline. Frames may contain block elements or Braille as well as ASCII. Never trim the text or interpret it as HTML. Display using textContent (or the framework's escaped text binding) in a pre with margin: 0, white-space: pre, font-family: monospace, font-size: 10px, line-height: 1, and letter-spacing: 0. Use a light foreground by default. Width and height are character cells, not pixels.
- Colour: frameEncoding is packed-12 or packed-bits. Read .bin as bytes; never decode binary frames as text. Both encodings are one most-significant-bit-first bit stream of row-major cells. Each cell holds meta.bitsPerGlyph bits of glyph index, then meta.bitsPerColor bits of palette index, then meta.bitsPerBackground bits of background palette index when that field is present and non-zero. packed-12 is the same stream with 7 + 5 bits (two cells per three bytes). Stop after width * height cells; trailing padding bits are zero. Resolve glyphs through meta.charset[glyphIndex] (index 0 is always a space) and colours through meta.palette[paletteIndex].
- Draw colour glyphs on a canvas with a 10px monospace font, textBaseline = top, cellWidth = ceil(measureText('M').width), cellHeight = 10. Clear the canvas on every frame and skip space glyphs. When a cell has a non-zero background index (two-tone half blocks), fill the lower half of the cell with that palette colour before drawing the glyph. Draw block elements as rectangles rather than font glyphs: █ full cell, ▀ top half, ▄ bottom half, ▌ left half, ▐ right half, ▘▝▖▗ single quadrants, ▚▞▙▛▜▟ quadrant combinations; draw ░ ▒ ▓ as the full cell at 28%, 52% and 78% opacity. Draw Braille (U+2801–U+28FF) as dots on a 2 × 4 grid inside the cell, using the dot bits of the code point. This keeps output identical across fonts. Scale the backing canvas for devicePixelRatio; preserve its logical aspect ratio when fitting the container. Blank cells are transparent; bgMode records the source background handling and is not a request to paint green or magenta. Monochrome whitespace is transparent too.
- Play at meta.fps using elapsed time: floor(elapsedMs * fps / 1000) % frameCount. Show frame 1 immediately, loop smoothly, and keep a single frame static. If fpsSource is default, the original frame rate was unavailable and the export uses 20 fps; make it adjustable.
- Use lazy loading and bounded fetch concurrency, cache loaded frames, pause while offscreen or the tab is hidden, and show a static first frame for prefers-reduced-motion. Clean up animation callbacks, observers, and pending requests when unmounted. Handle failed loads visibly. Avoid running browser APIs during server rendering.
- Fit the animation responsively without changing the character grid. Keep transparency so the surrounding project controls the background. Provide an accessible label, or mark purely decorative artwork as hidden from assistive technology.
